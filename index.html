① 默写必背 + 易错字

20 分钟

提纲原话：“第三单元古诗文默写、实词、翻译是硬分”。默写一分都不该丢，丢分几乎都丢在错别字上。

必背文言句子

不以物喜，不以己悲。
先天下之忧而忧，后天下之乐而乐。《岳阳楼记》
醉翁之意不在酒，在乎山水之间也。
醉能同其乐，醒能述以文者，太守也。《醉翁亭记》
雾凇沆砀，天与云与山与水，上下一白。
莫说相公痴，更有痴似相公者。《湖心亭看雪》

② 三篇文言：实词、通假、翻译、简答

15 分钟

先看词语自己说意思，再点开核对。只挑提纲列出的重点词。

通假字（4 个，必考）

原句通假
百废具兴（岳阳楼记）“具”同“俱”，全、都
属予作文以记之（岳阳楼记）“属”同“嘱”，嘱托
玉盘珍羞（行路难）“羞”同“馐”，美味的食物
直万钱（行路难）“直”同“值”，价值

《岳阳楼记》

谪守贬官做州郡长官
越明年到第二年
增其旧制扩大原有规模
胜状胜景
横无际涯宽阔无边
朝晖夕阴早晚阴晴明暗多变
迁客骚人被贬官者与文人
去国怀乡离开国都，怀念家乡
景（春和景明）日光
宠辱偕忘荣耀屈辱一并忘
微斯人微：如果没有
吾谁与归归：归依
翻译必考：“不以物喜，不以己悲” 是互文，要合起来译：不因外物的好坏和自己的得失而或喜或悲。

行文思路：叙事交代作记缘由 → 写洞庭湖“大观” → “若夫”（阴·悲）“至若”（晴·喜） → “嗟夫”转入议论，提出“古仁人之心” → “微斯人，吾谁与归”作结。

主旨：以“古仁人”之境对比常人之情，表达超越个人得失、以天下为己任的政治抱负。

简答：为何用大量篇幅写洞庭湖？写景为抒情议论作铺垫；两种景色引出两种览物之情，再与“古仁人之心”对照，中心自然而出。

《醉翁亭记》

蔚然茂盛的样子
翼然像鸟张开翅膀一样（名词作状语）
名之者谁名：命名（名词作动词）
辄醉辄：就
醉翁之意意：意趣、情趣
得之心而寓之酒得：领会；寓：寄托
林霏开 / 岩穴暝霏：雾气；开：消散；暝：昏暗
野芳 / 佳木秀芳：花；秀：茂盛
伛偻 / 提携弯腰曲背，指老人 / 被牵扶的孩子，指小孩
射者中，弈者胜射：投壶；弈：下棋
颓然倒下的样子，形容醉态
太守谓谁谓：是
  • 线索：“乐”——山水之乐 → 宴酣之乐 → 禽鸟之乐 → 太守之乐其乐。
  • 写景顺序：由远及近、由面及点：环滁皆山 → 西南诸峰 → 琅琊山 → 酿泉 → 醉翁亭。
  • 语言：连用 21 个“也”，语气舒缓咏叹。
  • 简答：写滁人游、众宾欢的用意？侧面写出滁州治理有方、百姓安乐，为“与民同乐”的主旨作铺垫。

《湖心亭看雪》

更定初更以后（更 gēng）
拏一小舟撑船（读 ná）
上下一白一：全
惟长堤一痕惟：只
芥小草，喻极微小
焉得更有此人焉得：哪能；更：还
强饮三大白强 qiǎng：尽力；白：罚酒用的酒杯，代指酒
痴痴迷、执着
  • “天与云与山与水，上下一白”好在哪？白描，三个“与”字写出水天一色的浑然，语言朴素而境界阔大。
  • 量词：一痕、一点、一芥、两三粒——量词精当，意境苍茫空阔。
  • 文眼：以“痴”字作骨：痴行、痴景、痴情。
文言翻译六字诀 留（年号、人名、地名、官职照留）· 删（无实义语气助词删去）· 换（古词换今词）· 调（倒装调回现代语序）· 补（省略成分补出）· 贯（译不通处意译贯通）

③ 诗词鉴赏：手法与典故

10 分钟

鉴赏题常考“用了什么手法”“典故指什么”“表达什么情感”。记住每首诗的 1–2 个考点即可。

诗句考点
停杯投箸不能食，拔剑四顾心茫然（行路难）以乐景（盛宴）衬苦闷
欲渡黄河冰塞川，将登太行雪满山（行路难）象征（人生道路艰难）
闲来垂钓碧溪上，忽复乘舟梦日边（行路难）用典：吕尚垂钓遇文王；伊尹梦乘舟过日边受汤聘
怀旧空吟闻笛赋，到乡翻似烂柯人（酬乐天·颔联）两典：向秀经嵇康旧居闻笛作《思旧赋》；王质观棋，斧柄已烂，归家已过百年

人有悲欢离合……此事古难全（水调歌头·下阕）理性宽解
寄书长不达，况乃未休兵（月夜忆舍弟）背景安史之乱，由家愁落到战乱之痛
秋草独寻人去后（长沙过贾谊宅）借凭吊贾谊抒写自身迁谪之悲

《水调歌头》小序：丙辰中秋，欢饮达旦，大醉，作此篇，兼怀子由。（熙宁九年，1076 年）

鉴赏答题格式（照着写就能拿步骤分） 赏析：手法 ＋ 结合诗句具体分析 ＋ 表达效果
炼字：释字义 → 说手法 → 述效果
情感主旨：由象到情，结合具体诗句与背景作答

④ 议论文：四篇思路 + 论证方法

10 分钟

提纲原话：“第二单元四篇议论文重在理清思路、辨明论证方法。”

先分清两个概念

  • 立论：正面阐明主张。驳论：通过批驳对方来树立自己观点。
  • 论点必须是完整的判断句（“骨气”不是论点，“我们中国人是有骨气的”才是）。
  • 论据：事实论据、道理论据。
看到……就是……论证
人名、史实、数据举例论证
名言、俗语道理论证（引用论证）
正反对照对比论证
以喻说理比喻论证

四篇一句话抓住

《中国人失掉自信力了吗》（鲁迅·驳论文）

  1. 摆出对方三条论据：自夸“地大物博”、只希望国联、求神拜佛
  2. 驳论证：信“地”信“物”信“国联”是“他信力”，求神拜佛是“自欺力”——论据与论点没有逻辑联系
  3. 立论：“我们有并不失掉自信力的中国人在”，他们是“中国的脊梁”
  4. 结论：“要自己去看地底下”

常考简答：“中国的脊梁”指什么？指脚踏实地为民族进步而奋斗的人；用“脊梁”作比喻，说明他们是支撑民族生存发展的中坚力量。

《谈骨气》（吴晗）中心论点：“我们中国人是有骨气的。”孟子三句作道理论据，统领三个事例：

孟子名句事例
富贵不能淫文天祥拒绝元朝诱降
贫贱不能移穷人不食“嗟来之食”
威武不能屈闻一多怒斥特务
易错三个事例的顺序不能调换，与孟子三句的先后一一照应。

《创造宣言》（陶行知）先树靶子——五种“不能创造”的借口（环境太平凡、生活太单调、年纪太小、太无能、山穷水尽走投无路），再逐条反驳。核心主张：处处是创造之地，天天是创造之时，人人是创造之人。

《培养德智体美劳……》（习近平·立论性政论文）开篇点明“培养什么人，是教育的首要问题”；再从六个方面讲“怎样培养”：坚定理想信念、厚植爱国主义情怀、加强品德修养、增长知识见识、培养奋斗精神、增强综合素质。多用排比形成气势。

论证思路题答题格式文章首先……，接着……，然后……，最后……（按层次分点写）

⑤ 现代诗意象 + 易混常识 + 字音

5 分钟

提纲原话：“第一单元六首诗读懂意象、体会情感即可。”最后 5 分钟扫一遍容易张冠李戴的地方。

意象对应（最容易安错）

《乡愁》《我爱这土地》
邮票 → 母子分离

坟墓 → 生死隔绝
海峡 → 家国之隔		 土地 → 苦难深重的祖国
河流、风 → 人民的悲愤与抗争

  • 《沁园春·雪》：上阕“望”字统领写雪景，下阕“惜”字统领评人物；“山舞银蛇，原驰蜡象”化静为动。
